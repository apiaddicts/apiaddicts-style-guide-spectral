The chosen parameter must be defined in this operation. By default, $limit

This rule applies only to collection GET endpoints that return paginated results (HTTP 206). Paths ending with a path parameter (e.g. `/users/{id}`) are treated as single-resource endpoints and are automatically excluded, since `$limit` has no meaning when returning a single resource. Paths matching `/me` (e.g. `/users/me`) and health check paths (`/status`, `/health`, `/ping`) are also excluded.
