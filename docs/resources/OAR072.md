Non OK responses shouldn't have stackTraces

Noncompliant Code Example (OpenAPI 2)
-------------------------------------

``` yaml
swagger: '2.0'
info:
  title: Sample API
  version: 1.0.0
paths:
  /sample:
    get:
      responses:
        '200':
          description: Successful operation
          schema:
            type: object
            properties:
              id:
                type: integer
                format: int64
              name:
                type: string
        '400':
          description: Bad request
          schema:
            type: object
            properties:
              code:
                type: integer
                format: int32
              message:
                type: string
              stackTrace: # Noncompliant {{OAR072: Responses other than 200 must not include the stack trace property 'stackTrace'.}}
                type: string
```

Compliant Solution (OpenAPI 2)
------------------------------

``` yaml
swagger: '2.0'
info:
  title: Sample API
  version: 1.0.0
paths:
  /sample:
    get:
      responses:
        '200':
          description: Successful operation
          schema:
            type: object
            properties:
              id:
                type: integer
                format: int64
              name:
                type: string
        '400':
          description: Bad request
          schema:
            type: object
            properties:
              code:
                type: integer
                format: int32
              message:
                type: string
              traceId:
                type: string
```

            type: string
