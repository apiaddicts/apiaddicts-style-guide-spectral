The 201 response schema of a POST operation must have properties named `data` or `error`, and each must have at least one sub-property.

**Rules:**
- Only applies to `201` responses of `POST` operations.
- Top-level property names must be exactly `data` or `error` (case-sensitive).
- Each `data`/`error` property must contain at least one sub-property.


Noncompliant Code Example (OpenAPI 2)
-------------------------------------

swagger: "2.0"
info:
  version: 1.0.0
  title: Swagger Petstore
paths:
  /endpoint:
    post:
      responses:
        201:
          description: Ok
          schema:
            $ref: '#/definitions/response'
        204:
          description: No content

definitions:
  response:
    type: object
    properties:
      result: \# Noncompliant {{OAR038: Response property must be named 'data' or 'error'}}
        type: object
        properties:
          id:
            type: string

Compliant Solution (OpenAPI 2)
------------------------------

swagger: "2.0"
info:
  version: 1.0.0
  title: Swagger Petstore
paths:
  /endpoint:
    post:
      responses:
        201:
          description: Ok
          schema:
            $ref: '#/definitions/response'
        204:
          description: No content

definitions:
  response:
    type: object
    properties:
      data:
        type: object
        properties:
          id:
            type: string
