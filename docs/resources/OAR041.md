A WSO2 x-scope on an operation always requires an x-auth-type definition.

An operation that declares `x-scope` must also declare `x-auth-type`, regardless of the HTTP verb. This applies to every operation in the document — `paths`, `webhooks`, and `components.pathItems` where applicable for the OpenAPI version in use.

Noncompliant Code Example (OpenAPI 2)
---------------------------------------------------------------------------------------

swagger: "2.0"
x-wso2-security:
  apim:
    x-wso2-scopes:
    - name: read
      key: read
      roles: READ_ROLE
      description: Allows users to view records
paths:
  /pets:
    get:
      x-scope: read

Compliant Solution (OpenAPI 2)
---------------------------------------------------------------------------------------

swagger: "2.0"
x-wso2-security:
  apim:
    x-wso2-scopes:
    - name: read
      key: read
      roles: READ_ROLE
      description: Allows users to view records
paths:
  /pets:
    get:
      x-scope: read
      x-auth-type: "Application & Application User"
