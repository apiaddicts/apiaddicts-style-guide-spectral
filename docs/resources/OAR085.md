The OpenAPI version must be one of the versions allowed by the organization.

By default the allowed versions are:

  2.0, 3.0.0, 3.0.1, 3.0.2, 3.0.3, 3.1.0, 3.2.0

The list is configurable through the `valid-versions` function option. A document whose `openapi` (or Swagger `swagger`)
version is not in the list is flagged.

Compliant Solution (OpenAPI 2)
------------------------------

  swagger: "2.0"
  info:
    title: Sample API
    description: This is a sample Swagger API.
    version: "1.0.0"
  paths: {} 

Noncompliant Code Example (OpenAPI 3)
-------------------------------------

  openapi: "4.0.0"  \# Noncompliant {{OAR085: version not in the allowed list}}
  info:
    title: Sample API
    description: This is a sample API.
    version: 1.0.0
  paths: {}

Compliant Solution (OpenAPI 3)
------------------------------

  openapi: "3.2.0"  \# Allowed by default
  info:
    title: Sample API
    description: This is a sample API.
    version: 1.0.0
  paths: {}
