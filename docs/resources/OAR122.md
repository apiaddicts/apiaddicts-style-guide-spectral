The API must define its servers with absolute `http` or `https` URLs, so the API gateway knows where to route the traffic. The APISIX initializer builds the upstream of the gateway from them (`adc convert openapi`) and fails without them.

**Rules:**
- OpenAPI 3: the root `servers` must be a non-empty list. Every server of the root, of each path item and of each of its operations (OpenAPI 3.2 `query` and `additionalOperations` included) must have a `url` that starts with `http://` or `https://` (lowercase) followed by a host, and that is a valid absolute URL once its variables are replaced by their `default` values. Relative URLs such as `/v1` are reported, also in OpenAPI 3.2 documents with `$self`.
- Every server variable must have a string `default`, and every variable used in a `url` must be declared.
- Callbacks and webhooks are not routed by the gateway and are not evaluated.
- OpenAPI 2: `host` must be defined as a host name with an optional port, without scheme or path. Every value of the root `schemes` must be `http` or `https` (without `schemes` the gateway uses `http`), and `basePath` must start with `/`.
- Servers reached through `$ref` are resolved and reported once, on the referenced definition. A `$ref` that cannot be resolved is reported on its `servers` list.

**Configurable parameters:** none.


Noncompliant Code Example (OpenAPI 2)
-------------------------------------

swagger: "2.0" \# Noncompliant {{OAR122: The host must be defined.}}
info:
  version: 1.0.0
  title: Greetings API
schemes:
  - wss \# Noncompliant {{OAR122: Server scheme must be http or https.}}
basePath: /api-greetings/v1
paths:
  /greetings:
    get:
      responses:
        200:
          description: Ok

Compliant Solution (OpenAPI 2)
------------------------------

swagger: "2.0"
info:
  version: 1.0.0
  title: Greetings API
host: greetings-service:8080
schemes:
  - http
basePath: /api-greetings/v1
paths:
  /greetings:
    get:
      responses:
        200:
          description: Ok

Noncompliant Code Example (OpenAPI 3)
-------------------------------------

openapi: 3.0.0 \# Noncompliant {{OAR122: At least one server must be defined in servers.}}
info:
  title: Greetings API
  version: 1.0.0
paths:
  /greetings:
    servers:
      - url: /api-greetings/v1 \# Noncompliant {{OAR122: Server URL must be an absolute http or https URL.}}
    get:
      servers:
        - url: https://{region}.greetings.example.com/api-greetings/v1
          variables:
            region:
              enum: [eu, us] \# Noncompliant {{OAR122: Server variable 'region' must have a string default value.}}
      responses:
        200:
          description: Ok

Compliant Solution (OpenAPI 3)
------------------------------

openapi: 3.0.0
info:
  title: Greetings API
  version: 1.0.0
servers:
  - url: http://greetings-service:8080/api-greetings/v1
    description: Upstream backend service
paths:
  /greetings:
    get:
      servers:
        - url: https://{region}.greetings.example.com/api-greetings/v1
          variables:
            region:
              default: eu
              enum: [eu, us]
      responses:
        200:
          description: Ok
