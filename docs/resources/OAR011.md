For resources that must be named with two or more words it is recommended to use the naming convention "kebab-case" (lowercase words separated by a hyphen) to increase the readability of the url.

**Configurable parameters:**

- `naming-convention` — `kebab-case` (default), `snake_case`, `camelCase` or `UpperCamelCase`, trimmed and case-insensitive. Any other value falls back to `kebab-case`.

| Convention | Compliant segments | Noncompliant segments |
|---|---|---|
| `kebab-case` | `customer-orders`, `onboarding`, `v1`, `v2.1`, `report.pdf` | `customerOrders`, `customer_orders`, `V1` |
| `snake_case` | `customer_orders`, `onboarding`, `v1`, `v2.1` | `customer-orders`, `customerOrders` |
| `camelCase` | `customerOrders`, `onboarding`, `v1`, `oauth2Tokens` | `CustomerOrders`, `customer-orders`, `customerID` |
| `UpperCamelCase` | `CustomerOrders`, `Onboarding`, `V1`, `Report.pdf` | `customerOrders`, `v1`, `CustomerID` |

-------------------------------------

  version: "1.0"
