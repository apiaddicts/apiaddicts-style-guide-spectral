Numeric schemas that declare a `format` must declare a VALID one: `int32` or `int64` for `integer`, and `float` or `double` for `number`.

Noncompliant Code Example (OpenAPI 2)
-------------------------------------


``` yaml
swagger: '2.0'
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      responses:
        200:
          description: A list of items
          schema:
            type: object
            properties:
              age: # Compliant for OAR016: a missing format is reported by OAR052 / OAR076
                type: integer
              quantity: # Noncompliant {{OAR016: Numeric types must use a valid format for their type}}
                type: integer
                format: float
              price: # Noncompliant {{OAR016: Numeric types must use a valid format for their type}}
                type: number
                format: decimal
```

Compliant Solution (OpenAPI 2)
------------------------------

``` yaml
swagger: '2.0'
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      responses:
        200:
          description: A list of items
          schema:
            type: object
            properties:
              age:
                type: integer
                format: int32
              quantity:
                type: integer
                format: int64
              price:
                type: number
                format: double
```

Compliant Solution (OpenAPI 3)
------------------------------

``` yaml
openapi: "3.0.0"

  version: 1.0.0

        200:

                type: object

                  quantity:
                    type: integer
                    format: int64
                  count:
                    type: integer
                    format: int32
```
