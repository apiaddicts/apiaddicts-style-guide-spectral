The API title must not match the configured forbidden regular expression.

This rule takes a single regular expression and raises an issue when `info.title` matches it.

By default the pattern is `(?!)`, an expression that never matches, so the rule forbids nothing
until it is configured.

Noncompliant Code Example (pattern `(?i)test|sandbox|untitled`)
---------------------------------------------------------------

openapi: 3.0.1
info:
  title: Test Payments API \# Noncompliant {{OAR117: Title 'Test Payments API' matches the forbidden pattern: (?i)test|sandbox|untitled}}
  version: 1.0.0
paths:
  /payments:
    get:
      responses:
        200:
          description: Ok

Compliant Solution (pattern `(?i)test|sandbox|untitled`)
---------------------------------------------------------

openapi: 3.0.1
info:
  title: Payments API
  version: 1.0.0
paths:
  /payments:
    get:
      responses:
        200:
          description: Ok

Noncompliant Code Example (pattern `^(?!.*\bAPI\b)` - the title must mention "API")
------------------------------------------------------------------------------------

openapi: 3.0.1
info:
  title: Payments Service \# Noncompliant {{OAR117: Title 'Payments Service' matches the forbidden pattern: ^(?!.*\bAPI\b)}}
  version: 1.0.0
paths:
  /payments:
    get:
      responses:
        200:
          description: Ok

Compliant Solution (pattern `^(?!.*\bAPI\b)`)
----------------------------------------------

openapi: 3.0.1
info:
  title: Payments API
  version: 1.0.0
paths:
  /payments:
    get:
      responses:
        200:
          description: Ok
