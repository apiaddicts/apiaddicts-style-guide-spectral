All parameters in query must be snake\_case: lowercase words of letters and digits separated by a single underscore, starting with a letter (`page_size`, `onboarding_status1`, `address_line2`, `sha256_checksum`). A leading `$` and/or `_` is allowed (`$filter`, `_page2`).

The rule checks the query parameters of every operation (OpenAPI 3.2 `query` and `additionalOperations` included) and of every path item, in paths, callbacks and webhooks, including the ones reached through `$ref`. Path, header, cookie, `formData` and `body` parameters are not checked, nor OpenAPI 3.2 `querystring` parameters, whose name is not sent.

-------------------------------------

``` yaml
swagger: '2.0'
info:
  title: Customer Onboarding API
  version: 1.0.0
paths:
  /customers:
    get:
      parameters:
        - name: onboarding_status1
          in: query
          type: string
        - name: userFirstName # Noncompliant {{OAR077: All parameters in query must be snake_case.}}
          in: query
          type: string
        - name: 2fa_required # Noncompliant {{OAR077: All parameters in query must be snake_case.}}
          in: query
          type: boolean
      responses:
        '200':
          description: OK
```
