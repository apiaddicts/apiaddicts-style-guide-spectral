The chosen parameter must be defined in this operation. By default, $select

This rule applies to collection GET endpoints. Paths ending with a path parameter (e.g. `/users/{id}`) are treated as single-resource endpoints and are automatically excluded, since `$select` has no meaning when returning a single resource.
