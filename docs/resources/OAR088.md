The $ref of a parameter must end with a corresponding suffix

**Configurable parameters:**

- `default-suffix` — the text every parameter `$ref` must end with (default `Param`). It is trimmed and compared literally and case-sensitively with the end of the whole `$ref`, so `.` or `$` have no special meaning. A blank or non-string value falls back to `Param`.

The rule checks the parameters of every path item and operation (all HTTP methods, OpenAPI 3.2 `query` and `additionalOperations`), callbacks, webhooks (OpenAPI 3.1+), `components.pathItems` (OpenAPI 3.1+) and `components.callbacks`, and every entry of `components.parameters` (`parameters` in OpenAPI 2) that is itself a `$ref`. Inline parameters are not checked.

Each `$ref` is reported once, where it is written. Chained `$ref`s are checked at every hop, and `$self` pointers are followed in OpenAPI 3.2. A `$ref` to a whole file is compared as written (`./parameters/limitParam.yaml` ends with `.yaml`). A `$ref` written in another file is reported on the `$ref` of the document that brings that file.

Configuration Example:
---------------------------------

```yaml
rules:
  apiq:OAR088:
    resolved: false
    given: "$"
    then:
      function: apq-parameter-ref-suffix
      functionOptions:
        default-suffix: "Param" # Default suffix.
```

Noncompliant Code Example (OpenAPI 2)
-------------------------------------

``` yaml
swagger: '2.0'
info:
  title: Pet Clinic API
  version: '1.0'
paths:
  /pets:
    get:
      parameters:
        - $ref: '#/parameters/petIdRef' # Noncompliant {{OAR088: The parameter $ref '#/parameters/petIdRef' must end with the suffix 'Param'.}}
        - $ref: '#/parameters/limitParam'
      responses:
        '200':
          description: List of pets
parameters:
  petIdRef:
    name: petId
    in: query
    required: true
    type: string
  limitParam:
    name: limit
    in: query
    type: integer
```

Compliant Solution (OpenAPI 2)
------------------------------

``` yaml
swagger: '2.0'
info:
  title: Pet Clinic API
  version: '1.0'
paths:
  /pets:
    get:
      parameters:
        - $ref: '#/parameters/petIdParam'
        - $ref: '#/parameters/limitParam'
      responses:
        '200':
          description: List of pets
parameters:
  petIdParam:
    name: petId
    in: query
    required: true
    type: string
  limitParam:
    name: limit
    in: query
    type: integer
```

Noncompliant Code Example (OpenAPI 3)
-------------------------------------

``` yaml
openapi: 3.0.3
info:
  title: Customer Onboarding API
  version: '1.0'
paths:
  /customers:
    get:
      parameters:
        - $ref: '#/components/parameters/startSlate' # Noncompliant {{OAR088: The parameter $ref '#/components/parameters/startSlate' must end with the suffix 'Param'.}}
        - $ref: '#/components/parameters/limitParam'
      responses:
        '200':
          description: List of customers
components:
  parameters:
    startSlate:
      name: $start
      in: query
      schema:
        type: integer
    limitParam:
      name: $limit
      in: query
      schema:
        type: integer
    pageSizeParam:
      $ref: '#/components/parameters/pageSize' # Noncompliant {{OAR088: The parameter $ref '#/components/parameters/pageSize' must end with the suffix 'Param'.}}
    pageSize:
      name: pageSize
      in: query
      schema:
        type: integer
```

Compliant Solution (OpenAPI 3)
------------------------------

``` yaml
openapi: 3.0.3
info:
  title: Customer Onboarding API
  version: '1.0'
paths:
  /customers:
    get:
      parameters:
        - $ref: '#/components/parameters/startParam'
        - $ref: '#/components/parameters/limitParam'
      responses:
        '200':
          description: List of customers
components:
  parameters:
    startParam:
      name: $start
      in: query
      schema:
        type: integer
    limitParam:
      name: $limit
      in: query
      schema:
        type: integer
    pageSizeParam:
      $ref: '#/components/parameters/limitParam'
```
