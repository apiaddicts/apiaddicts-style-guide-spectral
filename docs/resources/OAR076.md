Schemas using numeric types must declare a well-defined and standardized format.

Noncompliant Code Example (OpenAPI 2)
-------------------------------------

``` yaml
swagger: '2.0'
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      responses:
        200:
          description: A list of items
          schema:
            type: object
            properties:
              age: # Noncompliant {{OAR076: Schema should use well-defined type and format}}
                type: integer
              quantity: # Noncompliant {{OAR076: Schema should use well-defined type and format}}
                type: integer
                format: float
              price: # Noncompliant {{OAR076: Schema should use well-defined type and format}}
                type: number
                format: decimal
```

Compliant Solution (OpenAPI 2)
------------------------------

``` yaml
swagger: '2.0'
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      responses:
        200:
          description: A list of items
          schema:
            type: object
            properties:
              age:
                type: integer
                format: int32
              quantity:
                type: integer
                format: int64
              price:
                type: number
                format: double
```
