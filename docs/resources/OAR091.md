Parameters must contain only $ref references
All parameters defined at operation level must be defined using a $ref reference. Inline parameter definitions are not allowed.

Noncompliant Code Example (OpenAPI 2)
-------------------------------------

Inline parameters are defined directly inside the operation instead of using $ref.

``` yaml
swagger: "2.0"
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      summary: Get items
      parameters: # Noncompliant {{OAR091: Parameters must contain only $ref references}}
        - name: param1
          in: query
          type: string
        - name: param2
          in: header
          type: string
      responses:
        200:
          description: OK
    post:
      summary: Create item
      parameters: # Noncompliant {{OAR091: Parameters must contain only $ref references}}
        - name: id
          in: path
          required: true
          type: string
      responses:
        200:
          description: OK
```

Compliant Solution (OpenAPI 2)
------------------------------

``` yaml
swagger: "2.0"
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      summary: Get items
      parameters:
        - $ref: "#/parameters/Param1"
        - $ref: "#/parameters/Param2"
      responses:
        200:
          description: OK
    post:
      summary: Create item
      parameters:
        - $ref: "#/parameters/PathId"
      responses:
        200:
          description: OK
parameters:
  Param1:
    name: param1
    in: query
    type: string
  Param2:
    name: param2
    in: header
    type: string
  PathId:
    name: id
    in: path
    required: true
    type: string
```

Noncompliant Code Example (OpenAPI 3)
-------------------------------------

Inline parameters are declared directly inside the operation.

``` yaml
openapi: "3.0.0"
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      summary: Get items
      parameters: # Noncompliant {{OAR091: Parameters must contain only $ref references}}
        - name: param1
          in: query
          schema:
            type: string
        - name: param2
          in: header
          schema:
            type: string
      responses:
        200:
          description: OK
    delete:
      summary: Delete item
      parameters: # Noncompliant {{OAR091: Parameters must contain only $ref references}}
        - name: id
          in: path
          required: true
          schema:
            type: string
      responses:
        200:
          description: OK
```

Compliant Solution (OpenAPI 3)
------------------------------

``` yaml
openapi: "3.0.0"
info:
  version: 1.0.0
  title: My API
paths:
  /examples:
    get:
      summary: Get items
      parameters:
        - $ref: "#/components/parameters/Param1"
        - $ref: "#/components/parameters/Param2"
      responses:
        200:
          description: OK
    delete:
      summary: Delete item
      parameters:
        - $ref: "#/components/parameters/PathId"
      responses:
        200:
          description: OK
components:
  parameters:
    Param1:
      name: param1
      in: query
      schema:
        type: string
    Param2:
      name: param2
      in: header
      schema:
        type: string
    PathId:
      name: id
      in: path
      required: true
      schema:
        type: string
```
